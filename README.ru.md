# anki_manga

[English](README.md) · **Русский**

Читайте японскую мангу в Chrome и превращайте реплики из пузырей в карточки Anki почти без лишних действий.

- **Наведите** курсор на пузырь с [Yomitan](https://yomitan.wiki/), удерживая Shift. Текст пузыря распознаётся прямо на вашем компьютере и невидимо накладывается на картинку. Поэтому Yomitan работает на страницах манги, а предложение в карточке — ровно этот пузырь.
- **Кликните** по пузырю, и откроется боковая панель. В ней реплика с фуриганой, перевод, короткое объяснение, *почему сказано именно так*, и слова, которые стоит выучить.
- **«+»** добавляет в Anki подробную карточку: слово, чтение, значение, реплику с выделенным жирным словом, фуригану, перевод, грамматические заметки, картинку панели комикса и ссылку на страницу. Слова, которые уже есть в колоде, показаны серым.

Распознавание текста работает локально ([manga-ocr](https://github.com/kha-white/manga-ocr) и comic-text-detector через [mokuro](https://github.com/kha-white/mokuro)). Объяснения пишет DeepSeek по **вашему собственному** API-ключу. Отправляется только текст пузырей, по которым вы кликнули, и каждый ответ кэшируется: за один и тот же пузырь вы не платите дважды.

## Как это устроено

Частей две, и обе должны работать, пока вы читаете:

| Часть | Что это | Что делает |
|---|---|---|
| **Хелпер** | Небольшая программа, которую вы запускаете в Терминале (`anki-manga-helper`). Работает только на вашем компьютере и слушает только `127.0.0.1`. | Находит пузыри, распознаёт текст, кэширует результаты, общается с DeepSeek и Anki. |
| **Расширение** | Расширение Chrome с боковой панелью. | Отправляет страницы манги хелперу, кладёт невидимый слой текста для Yomitan, показывает объяснения и кнопки «+». |

Чтобы добавлять карточки, должен быть открыт Anki с AnkiConnect. Yomitan необязателен: без него можно кликать по пузырям, получать объяснения и добавлять карточки.

## Что понадобится

- **macOS.** Быстрее всего на Apple Silicon (M1 и новее). На Intel, Linux и Windows может заработать, но не проверялось.
- **Google Chrome** версии 116 или новее. Другие браузеры на Chromium могут подойти.
- Около **3 ГБ свободного места** под модели распознавания и PyTorch.
- **[Anki](https://apps.ankiweb.net/)** (десктопный) с дополнением **AnkiConnect**.
- **API-ключ DeepSeek** с небольшим балансом, для объяснений. Пары долларов хватает надолго ([стоимость](#приватность-и-стоимость)).
- **[uv](https://docs.astral.sh/uv/)**. Он сам установит хелпер и нужный ему Python, ставить Python вручную не нужно.

## Установка по шагам

Это делается один раз и занимает 15–20 минут, большая часть уходит на скачивание.

### Шаг 1. Установите uv

Откройте **Терминал** (⌘ Пробел, наберите «Терминал» или «Terminal», нажмите Enter) и вставьте:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Если у вас есть Homebrew, можно и так: `brew install uv`.

**Закройте Терминал и откройте снова**, затем проверьте:

```sh
uv --version
```

Должно появиться что-то вроде `uv 0.x.y`. Если видите `command not found`, откройте новое окно Терминала и попробуйте ещё раз.

### Шаг 2. Установите хелпер

```sh
uv tool install "git+https://github.com/Suraba03/anki_manga#subdirectory=helper"
```

Скачаются хелпер и его зависимости (самая большая из них — PyTorch), это займёт несколько минут. В конце будет строка `Installed 1 executable: anki-manga-helper`.

Если uv предупредит, что `~/.local/bin` нет в PATH, выполните `uv tool update-shell` и перезапустите Терминал.

### Шаг 3. Запустите хелпер (при первом запуске скачаются модели)

```sh
anki-manga-helper
```

При **первом запуске** скачиваются модели распознавания (около 500 МБ), это может занять несколько минут. Когда всё готово, хелпер напишет:

```
ready
```

Дальше запуск занимает несколько секунд. **Не закрывайте это окно Терминала, пока читаете**: если его закрыть, хелпер остановится. Чтобы остановить его специально, нажмите `Ctrl+C`. Чтобы хелпер запускался сам при входе в систему, см. [Автозапуск хелпера](#автозапуск-хелпера).

### Шаг 4. Установите Anki и AnkiConnect

1. Установите [Anki](https://apps.ankiweb.net/), если его ещё нет, и откройте.
2. В Anki: **Инструменты → Дополнения → Получить дополнения…** (Tools → Add-ons → Get Add-ons…), введите код **`2055492159`** и нажмите OK.
3. **Перезапустите Anki.**

Настраивать AnkiConnect не нужно. Anki просто должен быть открыт, когда вы добавляете карточки.

### Шаг 5. Установите расширение Chrome

Расширения нет в Chrome Web Store, поэтому оно загружается из папки:

1. Скачайте этот репозиторий. На GitHub нажмите зелёную кнопку **Code**, затем **Download ZIP**, и распакуйте архив туда, где он будет лежать постоянно, например `~/Applications/anki_manga`. Или выполните `git clone https://github.com/Suraba03/anki_manga.git`.
   > ⚠️ Chrome каждый раз загружает расширение из этой папки. После установки не удаляйте и не перемещайте её.
2. Откройте в Chrome **`chrome://extensions`**.
3. Включите **Режим разработчика** (Developer mode) — переключатель в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку **`extension`** внутри скачанного репозитория. Нужна именно `extension`, а не весь репозиторий.
5. Нажмите на значок пазла на панели Chrome и **закрепите** anki_manga, чтобы его значок был всегда на виду.

### Шаг 6. Подключите расширение и добавьте ключ DeepSeek

1. Получите ключ: зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/), пополните баланс на небольшую сумму в разделе **Top up**, затем откройте **API keys → Create new API key** и скопируйте ключ (он начинается с `sk-`).
2. Нажмите на **значок anki_manga** на панели. Справа откроется боковая панель.
3. Справа вверху должно быть зелёное **● Helper ready**. Если нет, см. [Если что-то не работает](#если-что-то-не-работает).
4. Раздел **⚙ Settings — API key & deck** в первый раз откроется сам. Вставьте ключ и нажмите **Save**. Должна появиться надпись **Key saved.**
5. Выберите **колоду** (deck), куда будут попадать карточки. Список берётся из Anki, поэтому Anki должен быть открыт.

После этого в Anki появится тип записей **Manga Mining (anki_manga)**. Настраивать его не нужно.

Ключ хранит только хелпер на вашем компьютере. Он никогда не сохраняется в расширении и никуда не отправляется, кроме DeepSeek.

### Шаг 7. Установите Yomitan (рекомендуется)

1. Установите [Yomitan из Chrome Web Store](https://chromewebstore.google.com/detail/yomitan/likgccmbimhjbgkjambclfkhldnlhbnn).
2. На его приветственной странице импортируйте словарь. Хороший японско-английский словарь — [Jitendex](https://jitendex.org/).
3. Yomitan ищет слово, когда вы **держите Shift и водите мышкой** по тексту. Так он работает по умолчанию, и anki_manga на это рассчитывает.
4. Необязательно: настройте вкладку Anki в Yomitan, чтобы его собственная кнопка «+» тоже создавала карточки. См. [Тот же тип записей в Yomitan](#тот-же-тип-записей-в-yomitan).

Установка закончена.

## Первая глава

1. Откройте главу на сайте, где читаете мангу. Подходят и «ленточные» читалки с прокруткой, и читалки по одной странице.
2. Откройте боковую панель (значок anki_manga) и нажмите **Enable on this site**. Chrome попросит доступ **только к этому сайту**. Нажмите **Разрешить**.
3. Многие сайты берут картинки с отдельного сервера. Если в панели появится кнопка вроде **Allow images from cdn.example.com**, нажмите её один раз и разрешите доступ.
4. Следите за **значком в правом верхнем углу каждой страницы**:
   - `⏳ finding bubbles…` — хелпер ищет пузыри;
   - `⏳ 4/11` — распознано 4 пузыря из 11;
   - `✓ 11` — всё готово, значок скоро исчезнет;
   - `⚠ …` — что-то не так, текст подскажет, что именно. Значок не исчезнет, пока проблема не решится.

   В панели есть сводка по вкладке, например `Pages: 6 ready · 1 recognizing`.
5. **Зажмите Shift и наведите** курсор на слово в пузыре — появится окно Yomitan.
6. **Кликните** по пузырю (без Shift). В панели появятся:
   - реплика **с фуриганой** (сразу);
   - **перевод** и **грамматические заметки**, почему сказано именно так (через секунду-две);
   - **предложенные слова**, у каждого кнопка **+**.
7. Нажмите **+** рядом со словом: карточка появится в колоде, а в строке будет `✓ added`.

Страницы обрабатываются чуть раньше, чем вы до них докручиваете, так что обычно пузыри уже готовы. Если навести курсор на ещё не распознанный пузырь (у него пунктирная рамка), он встанет в очередь первым.

## Каждый день

1. Откройте Anki.
2. Запустите хелпер: `anki-manga-helper` в Терминале (или настройте [автозапуск](#автозапуск-хелпера)).
3. Читайте в Chrome. Включённые сайты остаются включёнными.

| Действие | Как |
|---|---|
| Посмотреть слово | Зажать **Shift** и навести курсор (Yomitan) |
| Объяснить пузырь | **Кликнуть** по нему, или навести курсор и нажать **Alt+E** |
| Добавить карточку | **+** рядом с предложенным словом в панели |
| Показать или скрыть невидимый слой текста (проверить, ровно ли он лёг) | **Alt+V** |
| Выключить на сайте | Панель → **Disable on this site** |

Читалки, которые рисуют страницы в `<canvas>`, а не картинками, тоже работают — через снимок экрана. Страница должна целиком помещаться на экране, а Chrome один раз спросит разрешение на снимки.

### Что в карточке

Поля типа записей **Manga Mining (anki_manga)**:

| Поле | Содержимое |
|---|---|
| Word | слово, которое вы добавили |
| Reading | чтение каной |
| Meaning | краткое значение |
| Sentence | весь пузырь, слово выделено **жирным** |
| SentenceFurigana | пузырь с фуриганой |
| SentenceTranslation | перевод |
| Explanation | грамматические заметки |
| Picture | панель комикса, в которой этот пузырь |
| Source | ссылка на страницу |

У карточек тег `anki_manga`. Шаблон можно переоформить в Anki (**Инструменты → Управление типами записей → Manga Mining (anki_manga) → Карточки**), и ваши изменения сохранятся.

## Дополнительно

### Автозапуск хелпера

Чтобы больше не открывать Терминал, можно сделать так, чтобы macOS сама запускала хелпер при входе в систему и перезапускала его, если он остановится. Один раз вставьте в Терминал:

```sh
mkdir -p ~/Library/LaunchAgents
cat > ~/Library/LaunchAgents/com.anki-manga.helper.plist <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.anki-manga.helper</string>
  <key>ProgramArguments</key><array><string>$HOME/.local/bin/anki-manga-helper</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>$HOME/Library/Logs/anki-manga-helper.log</string>
  <key>StandardErrorPath</key><string>$HOME/Library/Logs/anki-manga-helper.log</string>
</dict>
</plist>
EOF
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.anki-manga.helper.plist
```

- Проверить, что работает: `tail ~/Library/Logs/anki-manga-helper.log` — последняя строка должна быть `ready`.
- Перезапустить (например, после обновления): `launchctl kickstart -k gui/$(id -u)/com.anki-manga.helper`
- Отключить: `launchctl bootout gui/$(id -u)/com.anki-manga.helper && rm ~/Library/LaunchAgents/com.anki-manga.helper.plist`

Если `which anki-manga-helper` показывает другой путь, а не `~/.local/bin/anki-manga-helper`, впишите в файл его.

### Тот же тип записей в Yomitan

Кнопка «+» в самом Yomitan работает так, как вы её настроили. Чтобы её карточки выглядели так же, как карточки из панели:

1. В Yomitan откройте **Settings → Anki** и включите **Enable Anki integration**.
2. **Configure Anki card format…**: выберите колоду и модель **Manga Mining (anki_manga)**.
3. Сопоставьте поля:

| Поле | Значение |
|---|---|
| Word | `{expression}` |
| Reading | `{reading}` |
| Meaning | `{glossary-brief}` |
| Sentence | `{cloze-prefix}<b>{cloze-body}</b>{cloze-suffix}` |

Остальные поля оставьте пустыми: их заполняет панель, когда вы добавляете карточку оттуда. Каждый пузырь — отдельный блок текста, поэтому `{sentence}` в Yomitan — это ровно один пузырь.

## Обновление и удаление

**Обновить:**

```sh
uv tool upgrade anki-manga-helper
```

Потом перезапустите хелпер. Расширение: скачайте репозиторий заново в **ту же папку** (или выполните там `git pull`). Затем в `chrome://extensions` нажмите **↻** у anki_manga и перезагрузите вкладки с мангой.

**Удалить:**

```sh
uv tool uninstall anki-manga-helper
rm -rf ~/Library/Application\ Support/anki_manga ~/Library/Caches/anki_manga
```

Затем удалите расширение в `chrome://extensions`. Если настраивали автозапуск, сначала отключите его (см. выше). Модели лежат в `~/.cache/huggingface` и `~/.cache/manga-ocr`, их можно удалить, чтобы освободить место. Карточки в Anki останутся.

## Если что-то не работает

**Сначала проверьте три частые причины:**
1. Запущен ли хелпер? В его окне Терминала должно быть `ready`.
2. Открыт ли Anki? Он нужен только для колод и карточек.
3. Перезагрузили ли вы вкладку с мангой после включения сайта или обновления расширения?

| Что видите | Что делать |
|---|---|
| В панели **● Helper not running** / значок `⚠ helper not running` | Запустите `anki-manga-helper` в Терминале. Страницы повторят попытку сами. |
| В панели **Loading OCR models…** / значок `⏳ helper starting…` | Подождите: 3–10 секунд, при самом первом запуске — несколько минут. |
| В панели **● Model loading failed** | Посмотрите ошибку в окне Терминала с хелпером. Чаще всего прервалось первое скачивание моделей: остановите хелпер (`Ctrl+C`) и запустите снова. |
| **This helper is paired with another install** | Бывает после переустановки расширения. Выполните `anki-manga-helper --reset-pairing`, перезапустите хелпер и откройте панель заново. |
| Значок `⚠ not paired — open the side panel` | Откройте боковую панель один раз, она подключится сама. |
| Кнопка **Allow images from …** / значок `⚠ allow images in the side panel` | Нажмите кнопку в панели и разрешите доступ. |
| Значок `⚠ extension reloaded — refresh the page` | Перезагрузите вкладку (⌘R). |
| Значок `⚠ can't load this image` | Сайт не даёт скачивать картинки напрямую. Расширение попробует снимок экрана: разрешите снимки, если спросит. |
| Значков нет, ничего не происходит | Проверьте, что в панели написано **Disable on this site** (значит, сайт включён). Перезагрузите вкладку. Если всё равно пусто, посмотрите строку `Pages:` в панели. |
| Yomitan не появляется | Держите **Shift**, когда наводите курсор. Проверьте, что Yomitan включён и в нём есть словарь. Нажмите **Alt+V**: если красный текст не появился, страница ещё не обработана (смотрите на значок). |
| Красный текст (Alt+V) сдвинут относительно пузырей | Немного измените размер окна. Если не помогло, создайте issue с названием сайта и скриншотом. |
| **Anki isn't running…** | Откройте Anki. Объяснения работают и без него, а карточки добавятся, только когда Anki открыт. |
| **Add your DeepSeek API key in Settings…** | Settings → вставьте ключ → Save. |
| **DeepSeek rejected the API key** | Проверьте ключ на platform.deepseek.com или создайте новый. |
| **Your DeepSeek account has no balance** | Пополните баланс на platform.deepseek.com. |
| `command not found: anki-manga-helper` | Выполните `uv tool update-shell` и перезапустите Терминал. |

**Где что хранится** (macOS):
- Настройки и API-ключ: `~/Library/Application Support/anki_manga/config.json`. Читать его может только ваш пользователь.
- Кэш (распознанный текст, объяснения, последние 300 страниц): `~/Library/Caches/anki_manga/`. Его можно спокойно удалить.
- Если задать `ANKI_MANGA_HOME=/какая/то/папка`, и то и другое будет храниться там.

Ничего не помогло? [Создайте issue](https://github.com/Suraba03/anki_manga/issues) и напишите, что показывают панель и окно Терминала с хелпером.

## Приватность и стоимость

- **Страницы манги не покидают ваш компьютер.** Они попадают только к хелперу на `127.0.0.1`. Хелпер слушает только локальный адрес, отклоняет запросы от веб-страниц и принимает только это расширение (оно подключено секретным токеном).
- **DeepSeek получает только текст пузыря, по которому вы кликнули**, и только один раз. Ответ кэшируется, повторный клик по тому же пузырю бесплатен.
- **API-ключ** хранится только в локальном файле настроек хелпера (права 0600). Его нет ни в расширении, ни в синхронизации Chrome, ни в этом репозитории.
- **Стоимость:** одно объяснение — несколько сотен токенов, то есть крошечная доля цента на `deepseek-chat`. Целая глава, где вы кликнули по каждому пузырю, обычно стоит меньше цента. Цены — на [странице DeepSeek](https://api-docs.deepseek.com/quick_start/pricing).

## Разработка

```sh
cd helper && uv sync --extra dev && uv run pytest -m "not models"   # быстрые тесты
ANKI_MANGA_SAMPLES=/path/to/pages uv run pytest -m models             # тесты с настоящими моделями
uv run anki-manga-helper                                              # запуск из исходников
cd extension && node --test                                           # логика расширения
```

- После правок в расширении: `chrome://extensions` → ↻ → перезагрузите вкладку.
- Ручные проверки в браузере: [`extension/test/manual-checklist.md`](extension/test/manual-checklist.md).

**Планы:**
- **v2:** объяснения под ваш уровень и уточняющие вопросы по пузырю.

- **v4:** подсказки на основе слов, которые вы часто ищете.
- **Потом:** собственный словарь во всплывающем окне, без Yomitan.
